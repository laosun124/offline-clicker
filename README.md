# 离线连点器

一个 Android 连点器。可以把点击、长按、滑动和多指手势排成动作序列，保存为不同方案，按设定的间隔和次数执行。

## 功能

- 添加单点点击、长按、路径滑动和多指操作，支持录制动作。
- 调整动作顺序、时长、间隔和重复次数，设置开始前等待和循环次数。
- 新建、复制、重命名和删除方案，通过 JSON 文件导入或导出备份。
- 用悬浮控制开始、暂停和停止，查看动作标记、删除动作或返回应用。
- 悬浮控制可以拖动，也可以最小化到屏幕边缘。运行时会缩小并避开手势路径，点击边缘入口可暂停并展开。
- 浅色、深色和跟随系统三种外观。

## 安装与使用

支持 Android 7.0 及以上。在 Releases 下载 APK 安装。

1. 打开应用，在“设置”页开启无障碍服务。
2. 在“动作”页选择或新建方案，打开悬浮控制。
3. 切换到目标应用，通过“添加操作”选点，或使用“录制动作”。
4. 点击“开始”执行。默认等待 3 秒后运行 1 轮，循环数设为 0 可持续运行。
5. 运行时点击边缘入口暂停，再选择停止或继续。

部分系统会限制手动安装应用的无障碍权限，可在应用信息中查看“允许受限设置”。具体入口因手机而异。

## 方案与使用限制

方案保存在本机，卸载前请先导出备份。导入会新增方案，不会覆盖已有内容或自动运行。

每个方案最多 500 个动作，最多保存 50 个方案；多指手势最多 10 指，单次手势最长 59 秒。录制会逐次捕获、保存和转发手势，转发时需要稍候。

坐标按屏幕比例保存，屏幕方向、显示缩放或目标应用布局改变后，请检查动作位置。锁屏或屏幕尺寸变化会停止执行。设定的间隔从前一个手势完成后计算，实际执行速度也受系统调度影响。

若手势覆盖范围过大，找不到放置悬浮入口的位置，应用会停止执行。

## 权限

需要开启无障碍服务来显示悬浮控制和执行手势。应用不读取窗口内容、不截图、不监听音量键，也不申请联网权限。导出文件的位置由你通过系统文件选择器指定。

## 构建

需要 Python 3、JDK 17、Android SDK platform 34 和 build-tools 34.0.0。

```sh
python3 test.py
python3 build.py --sdk /path/to/android-sdk
python3 audit.py --sdk /path/to/android-sdk
```

安装包输出到 `build/`。版本号在 `version.properties` 中配置。签名文件不包含在仓库里；首次构建会生成自己的签名，通常不能直接覆盖安装 Release 中的版本。
